# Приватный scratch исторической проекции FindNode

S3C1 добавляет один фиксированный scratch к исходному dormant owner. Это неактивный этап подготовки: четыре приватных метода не имеют production callers. Публичный API, Node, leaf, Ready, допуск, подготовка source companion, учёт и чтение часов не меняются. Прежние тела конструкторов и Seal сохранены точно.

После проверки исходного owner/cut и ограниченной позиционной формы tryOwnedAttempt захватывает атомарный lane до выделения одного фиксированного claim. Копии wrapper используют общий claim и phase. Project/query требуют LIVE→BUSY; конкурент сразу получает отказ. Release требует LIVE→CLOSING, очищает оба полных массива, счётчики, maximum и projected, публикует CLOSED и только затем освобождает lane. Release при BUSY сохраняет владение. Старый CLOSED alias не может очистить следующий borrow: он ссылается на свой прежний claim, а неизменяемые owner/cut не стираются. Вызывающий обязан release на каждом unwind; аварийный OOM/panic или брошенный claim не имеют обещания восстановления доступности.

Длины targets/offered ограничиваются прежним 512 до дедупликации. Копируются только запрошенные bounded факты и четыре свидетеля на цель. Все originals сканируются для maximum и позиционного класса даже при пустых targets/offered. Offered сопоставляется по точному Session handle; отсутствующая Session получает отказ. Дубликаты целей и offered схлопываются. Ошибка очищает частичные массивы, сохраняя тот же LIVE borrow для исправления или release. Повтор успешной проекции отклоняется без замены первого результата. Во время вызова входы должны быть стабильны по обычным правилам Go races; последующая мутация входных массивов результат не меняет.

Исторические q и классы определяют порядок. Contact/Selected защищены и не занимают oldest-four. IncomingPinned конкурирует даже молодой и не становится автоматически защищённой. Ordinary входит при возрасте ровно 600 секунд. Порядок — opened, затем ConnID по прежнему comparator. Target link исключается только из свидетелей своей цели, но остаётся в originals и maximum. Query требует точную offered Session и представленную цель; source==target отклоняется. Результат — только исторический Protected/Aged/New. Session, закрытая после Seal, остаётся в проекции. Проверка **всех** originals после actual final sample ещё обязательна позднее.

Пусть B=512, N — число originals (N≤M), D/P — входные длины targets/offered до дедупликации (≤B). Консервативная граница работы: O(B+N*(1+D+P)+D²+P²), включая полную очистку массивов, скан originals, поиск offered, вставку четырёх свидетелей и линейную дедупликацию. При D=P=0 остаётся O(B+N); при N=0 сохраняются bounded проверки, очистка и дедупликация. Query — O(D+P+1), release — O(B+1). Дополнительный scratch — O(B), без нового M-размерного вектора/map. Claim удерживает прежний cut и его O(N) evidence без копирования. CLOSED aliases, отдельные owners и неограниченно удерживаемые cuts не дают общей границы S*M или retained handles. Это логические оценки, не измеренная приёмка CPU/RSS/задержек.

Новые mutable данные ограничены исходным owner.scratch и приватными phase/projected. Coordinator/source/pending/calendar/group/capacity, token/ID/round/cursor/watermark, sourceWindows и история не затрагиваются. Guards разрешают только четыре новых old-type sites и два policy identifier sites, без file-wide исключения. RAW36, Node body13, leaf importer14 и closure прежних Session helpers остаются точными.

Подготовлены восемь функциональных parents с32 детьми и два SOURCE parents с12 controls: настоящие TLS/original-domain/Seal fixtures, фиксированные contenders, copy/shape/refusal, независимые target-relative witnesses и снимки прежнего учёта. Приватная инъекция BUSY проверяет только механику отказа; это не доказательство реального adjacent-instruction расписания. Восемь причинных physical recipes остаются будущими. Source authoring не заявляет TYPE, SOURCE guard, functional/race PASS или mutation RED.

Отдельно остаются authoritative pending/source snapshots, исходный combined final lease и actual sample-all, f≥q/строгая граница, joint trials/source CAS/безотказный commit, writer/Ready closure, loaded hint, совокупные ресурсы, профили, G2 и активация. Новых deployment defaults или решений политики здесь нет.
