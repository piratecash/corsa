# Private historical owned round plan (SOURCE-only)

This unused unit prepares one historical order ticket from the SAME original dormant owner and already-complete projection. It allocates one fixed512-row workbook before coordinator.mu -> pending.mu. A LIVE->BUSY claim excludes copied-wrapper release/projection while rows, exact owner/pointer/generation, immutable request/session facts, cursor/watermark and RR cells are copied. Both application locks release before bounded fixed-index ordering. Every return restores LIVE. Complete missing projection refuses; it never drops a row or returns a partial ticket.

The frozen order is protected cursor rotation, aged opened/ConnID, then one turn per frozen accounting cell before its second, with within-cell Session rotation. Unknown physical names remain the ONE overflow cell. Old map/slice comparator and interleave remain a separate frozen test reference; a directed twelve-ConnID expected sequence guards against common comparator errors. The private claim retains a plan pointer once; release clears it before CLOSED and before borrowed=false. Old copied tickets cannot access a later borrow through a reused claim.

No R, clock sample, advance/cleanup, capacity observation, pending priority/phase, round/open/cursor/RR/watermark, ID, source binding, quota or diagnostic state is changed by preparation. Every q is historical; no f exists here. The opaque ticket has no getter/iterator/admission method. Concurrent later changes may stale it. It does not exclude every owner writer.

A future driver must revalidate the full scheduling/row snapshot, preserve refusal cleanup of original generations and accepted obligations, and obtain an exact success receipt or same-lock progress for successful cursor/RR updates. Existing C3a per-candidate Sample-all-originals/strict q-f/last-CAS/fixed suffix/Release ordering is byte-identical. No whole-round lease, real receive provenance, Ready writer closure, dispatch/T integration, profile choice, physical/FORMAT/TYPE/QA/RED or G2 follows.
