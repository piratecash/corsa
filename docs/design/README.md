# CORSA — макет интерфейса, просмотр изображения

Дизайн-документ CORSA. В этой поставке — просмотр изображения внутри
приложения; правки из предыдущих поставок уже реализованы и в архив не
вложены.

## Что здесь лежит

| Файл | Что это |
| --- | --- |
| `CORSA Design.html` | автономная копия макета: двойной клик, работает офлайн |
| `CORSA Mobile.dc.html` | сам документ — все экраны и дизайн-система |
| `support.js` | рантайм, который его отрисовывает |
| `android-frame.jsx` | рамка телефона (Android, 412×892) |
| `CHANGES-image-viewer.md` | что нужно сделать в Go |

## Компоненты действий

На экране `7a` показана палитра обычных кнопок, на `7c` круглый крестик, на `7d` оболочка модалки. Геометрия существующих прямоугольных кнопок сохраняется. «Выполнить» использует основной синий цвет, «Новая версия» использует оранжевый. Для копирования рядом с данными используем квадратную кнопку с иконкой. Вкладки, «Отправить», смайлы и плитка «Мой identity» имеют собственные компоненты.

«Мой identity» и карточка контакта используют одну модалку по содержимому с затемнением 85%. ID копируется кнопкой рядом с адресом, если основное действие внизу копирует ссылку с ключом. У карточки без ключа основное действие копирует ID. [Компоненты в документации UI](../ui.md#shared-action-components).

В узком окне «Консоль» стоит над статусом сети. Кнопка использует вторичный стиль, обе строки занимают всю ширину. Пример показан на экране `7f`.

## Экраны по этой функции

| Экран | Что показывает |
| --- | --- |
| `8a` | desktop — просмотр поверх чата, стрелки по бокам изображения, полоса миниатюр |
| `8b` | телефон — на весь экран, свайп по изображению, стрелки у карусели миниатюр |
| `8c` | компонент и состояния: одно изображение, загрузка, не-изображение |
| `7d` | modal shell — оболочка, на которой собран просмотрщик |
| `7c` | close button — та же кнопка 44 круг во всех местах просмотрщика |

У каждого экрана в макете есть бейдж с этим id — на него удобно ссылаться в обсуждении.

## Как посмотреть

Двойной клик по `CORSA Design.html` — работает офлайн, ничего ставить не нужно.

## Как доработать

Открыть `CORSA Mobile.dc.html` в Claude и описать правку словами. Документ — обычный
HTML, правки видны обычным диффом. Автономную копию после правок нужно пересобрать —
она не обновляется сама.

## Откуда взяты значения

Цвета, размеры, отступы и радиусы — литералы `color.NRGBA` / `unit.Dp` из
`internal/app/desktop`. Просмотрщика в коде нет, поэтому его значения выведены из
оболочки консоли и кнопок; новых цветов не вводилось. Подписи — английский каталог из
`i18n.go`.

Отличия макета от кода намеренные: шрифт Go заменён на IBM Plex Sans (в браузере
семейства Go нет), иконки — веб-версия того же Material Design, изображения и QR —
штрихованные заглушки.
