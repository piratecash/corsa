# Закрытые исходные сессии после настоящего измерения времени

Этот неактивный фрагмент D1 находится в `internal/core/findnode/owned_originals.go`. Производственных вызывающих мест нет; допуска он не даёт. Фрагмент не строит Node cut, не завершает построение runtime domain, не включает Ready, не выбирает предел развёртывания и не активирует FindNode.

`prepareOwnedOriginalSet(originals, maxMembers)` отклоняет неположительную или переполняющую арифметику байтов элемента явную границу и вход длиннее этой границы. Проверяются настоящее доказательство Session и неизменяемая identity, ненулевые ConnID/group, неотрицательное opened и открытое состояние. Повтор ConnID, включая разные handle с одним ID, отклоняет весь набор. Временная карта повторов и копия вектора создаются до финальных блокировок. Подготовленный пустой вектор отличается от неподготовленного нулевого значения. Это граница количества и арифметики элементов, а не измеренный RSS, стоимость map/GC, предел одновременных владельцев или задержка.

Закрытый вектор хранит каждый точный исходный handle независимо от выбора цели и приоритета. Изменение входного массива после подготовки не заменяет сохранённые handle. Набор не подтверждает Node owner/domain, классы или полноту. У Session сейчас есть логический opened без метки bridge-domain; сам фрагмент не умеет отклонить набор из чужого домена.

`sampleAndCheckOriginals(lease)` сначала отклоняет неподготовленное нулевое значение, затем ровно один раз вызывает настоящий `Sample()` переданной комбинированной reservation. Ошибка Sample не возвращает точку. Только после успеха проверяется каждый исходный handle через закрытый `Session.valid()`; хотя бы один закрытый даёт `ErrUnauthenticated` без точки. Финальный helper не добавляет явного выделения памяти, callback, блокировки, изменения Session, Release или Complete.

`Session.closed` меняется только из false в true. Открытый флаг, прочитанный после sample, поэтому подтверждает открытость этого точного handle в момент sample. Доступность на момент возврата не обещается. PendingTable, TargetCache, SigningCalendar и неактивный intake coordinator могут закрыть Session без изменения поколения отдельного bridge-domain; равенство поколения не заменяет полную проверку.

Вызывающий код непрерывно владеет ТОЙ ЖЕ настоящей комбинированной reservation во время helper и будущего commit. На успехе и отказе он освобождает её ровно один раз, без конкурентного terminal alias. Историческая точка не удерживает lease. Здесь нет вызывающего commit и source CAS; их непрерывное владение и линеаризация остаются дальнейшими SOURCE-обязательствами.

Рецепты новых тестов используют настоящее TLS/session proof, явные логические ConnID/group/opened и настоящие reservation запечатанного FixtureDomain. Это проверка только фрагмента sample/closed: не Node/CM capture одного домена, не полная классификация приоритета, не ресурсная приёмка и не десятисекундное ожидание. До запуска каждой TLS-задачи зарегистрированы отмена, закрытие сокетов и точный join.

Детерминированный рецепт порядка закрывает подготовленный handle, измеряет fixture-время10, получает отказ по closed и освобождает ту же reservation. Последующее измерение5 должно отклонить регрессию, потому что настоящий high-water mark leaf уже равен10. Перенос проверки closed перед Sample оставляет mark0 и меняет причинный результат. Остальные рецепты проверяют копирование handle, отказы по границе/повторам/proof, каждый путь закрытия, отказы Sample по Done/отрицательному/регрессии/MAX/nil/released и владение освобождением. Закрытый SOURCE inventory фиксирует тела, сигнатуры, форму и ПУСТЫЕ production callers; его мутации в памяти — SOURCE-контроли, отдельно от физических FUNCTIONAL-рецептов.

На авторской передаче код и рецепты не исполнялись. Независимое CODE review, форматирование, компиляция, положительные прогоны и физические причинные контроли — отдельные шаги. Остаются настоящее создание Node roles, самый ранний BeginCapture, согласованное покрытие writers/readers, настоящее q, полная проекция, непрозрачный cut с owner/domain/stamp, временные границы, scratch/предел одновременных владельцев и финальный source CAS. Отказ существующего неактивного frontdoor не изменён.
