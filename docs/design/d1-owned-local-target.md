# D1 owned local target: core slice

This draft implements the local responder core for a dedicated, inactive D1
construction. It does not enable the production capability, seal construction,
or establish release readiness. Existing constructors remain inactive.

A local target belongs to one original executing intake and one identity. Its
constructor samples the retained original Observer clock while Constructing and
checks immutable domain and kind provenance with Consumer.MatchesPoint. This
check grants no CaptureStamp or admission lease; actual captures still require
Ready. A second local calendar cannot reset the accepted signing debt.

ReserveReceived accepts the existing strict original receive cell and complete
owned cut. The original receive determines the response deadline. Class and
priority information remain historical at q. The target owner first performs
mandatory cleanup and acquires its cache, calendar, and original source mutexes.
It stages bounded cache admission in detached recipient maps and coordinated
records before R. Fresh f validates the original set, strict cut boundary, and
absence of newly due cleanup. Only then does a bounded suffix install the staged
maps while preserving existing entry and coordinated-record identities. A refused
stage cannot change another accepted job or either signing budget.

Local work waits for the projected signing opportunity before Take. An alias at
the strict response deadline is refused because no legal T could execute there.
Take obtains all application mutexes, then the shared accepted-work clock and
current R in that order, before its fresh original Sample. The old selection cut
is neither retained nor re-applied. Other expired or redrawn rows cannot revoke
this exact accepted obligation. A lawful pre-T refusal preserves its alias and
shared ticket; exact End, stale generation or deadline retires only that work.
Under the same R it
consumes the exact original alias, per-node actual spacing, and per-source actual
credit, then consumes the shared one-shot ticket. This is local AdmittedAtT.
Forwarding writer Take has a separate meaning and cannot substitute for T.
Signing runs outside all state-owner locks.

Completion is mandatory after a signing success, error, or panic. It uses the
retained original Observer clock after application waits, including after an End
publication; it does not reacquire current-generation admission. It completes or
retires the exact original entry, never a replacement. Accepted projected and
actual debt is never refunded. End before T prevents debit; End after T permits
cleanup and suppresses delivery to the ended original session.

Local results use the shared opaque OwnedAnswerWork companion. Cached copies
retain this request's original response expiry, independently of the cache's
longer retention. Completion captures the original shared signing deadline before
cache completion retires its coordinated record. A duplicate whose earlier
receive would require a shorter deadline is conservatively refused; it cannot
retime an already accepted original alias. Answer writer admission checks the
same original source and strict response expiry and does not debit a forwarding
budget or create another local T.

An owned L1 signing promise retains bounded protection on its original row and
exact live recipients. A later class redraw cannot turn that outstanding promise
into a pressure victim. Protected duplicate recipients join the same promise.
Exact recipient End clears its retained reference; completion retires signing
protection after minting independent answer custody. Ready-cache and ordinary
legacy eviction retain their documented policy.

The current slice provides core authority and causal fixtures. Node self-target
routing, actual signing invocation, original answer queue/writer composition, and
local retirement binding before F1 escape remain separate integration work.
The forwarding ANSWER relay must retain the same two original sessions and IDs.
D1 chooses a known live neighbor matching the exact target identity; an unknown
target is silent. Recursive routing and a public initiator belong outside D1.
Ready remains disabled until all required writer, reader, and inverse edges are
implemented and verified. Resource profiles, G2, observations, and release and
activation decisions remain separate.
