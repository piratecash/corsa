# Private owned round execution slice (SOURCE only)

This unused slice consumes one historical C3b ticket under its same original claim. LIVE→BUSY covers the complete driver, including application waits and successive candidates. Every ordinary exit restores LIVE. Separately, the original plan's consumed bit retires all copied tickets after the first attempt; it is never reset by success, refusal or release.

Before any final reservation, the driver revalidates round/cut, coordinator and group generations, cursor/watermark/sweep/RR and the complete remaining original provisional row set. Every row comparison retains its original reservation pointer and generation, source/target, request, deadline and offered priority. Missing, changed, replaced or additional rows refuse. A new round/generation cannot acquire closure authority by later looking empty.

Each candidate then enters the shared C3a body under the original BUSY claim. Coordinator→pending→one calendar→target waits and unpublished allocations precede its own genuine reservation. The same reservation calls Sample then all-original closed checks, strict q/f/frontier and final accounting trials. The last fallible source CAS and existing fixed accounting suffix remain in that scope. Immediately after successful publication, a private exact receipt and cursor/lower-cell RR progress are written with those same locks and reservation held. Release precedes application unlocks and diagnostics. Receipt acceptance compares local immutable values; it never reinterprets a committed row after unlocking. There is no caller receipt input or admission conversion.

Refusal cancellation unlinks only exact current original provisional generations. It does not end or release Reserved, Dispatching, AwaitingAnswer or TerminalDispatch rows. Their aliases, source references, target correlation, mandatory writer Finish and projected/actual debt retain existing lifecycle ownership. Legitimate C3a time/capacity housekeeping may survive refusal. Aborting a stale plan leaves round closure untouched. A complete current plan closes its original round using successful protected cursor/wrap and frozen lower-cell RR facts; an empty open plan renews the copied maximum without acquiring a final reservation. Empty execution does not replace existing accepted-row expiry/lifecycle paths.

Causal fixtures use genuine TLS proofs and tagged FixtureDomain authority, with explicitly logical receive time/classes/profile inputs. They cover stale snapshots before Sample with an independent clock high-water witness, an interleaved new original, forged/stale receipt tuples, successful cursor/RR, preserved accepted debt in four lifecycle phases, BUSY exclusion, replay and empty closure. Source controls pin exact placement, original generations, receipt-before-Release and foreign roots. These fixtures and controls have not been compiled or executed here.

Genuine production receive time, strict dispatcher and admission provenance, full writer/reader/inverse-edge closure for SealConstruction/Ready, Dispatch/Take/Finish/T integration, loaded-hint bootstrap, measured resource profiles and activation/G2 remain separate unfinished slices. This code adds no production caller, exported API, new default, configured numerical resource profile or Ready claim. Historical/current native facts are not transferred to this new virtual composition.
