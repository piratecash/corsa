# О1а: диагностический sender вернул false

Короткая компонентная попытка `97a9c06a6fe700ed0cf2c98e8a19f152` завершилась исходным Go **FAIL через 30,60 секунды**. Первая причина наблюдателя — **31**, транспортный код — **95**: `observer_full_send_finish_sender_false`. Это подтверждает возврат `sentAll=false` исходным отправителем полного набора маршрутов. Какая внутренняя ветвь сработала — сборка кадра, dispatch или пропуск записи при разбиении — **UNKNOWN**. Причины прежних c01 и 480-секундного отказов также остаются UNKNOWN.

Только три приватных диагностических файла различают семнадцать прежних ветвей отказа full-send. Исходные условия, порядок короткого замыкания, часы, блокировки и sticky-ошибка сохранены. Эти изменения не применялись к рабочему дереву продукта. Пройдены **43 внешних теста / 274 дочерних случая**, включая исходные sender/очередь и комбинации finish/projection. Собраны четыре Linux ELF-артефакта теста/стенда с новой проверкой исходным Go API, static ELF и BuildInfo; прежний exporter использован по точному совпадению зависимостей. Пять QA-файлов в эти ELF-артефакты не входят.

Тест штатно завершился с кодом 1, exporter — с кодом 0; все дочерние процессы гостя reap-подтверждены. Четыре события Native и выход worker с кодом 0 позволили ROOT/TESTER/REVIEWER подтвердить только остановку и очистить свой lock. Физические ресурсы XPC остаются UNKNOWN. Штатное завершение не меняет функциональный FAIL.

[Переносимый пакет](evidence/d1-full-send-sender-2026-11-20/README.md) сохраняет полные новые RAW, восстанавливаемую капсулу исходников, приватные правки, контроллеры, описи и ревью. Он ссылается на [предыдущее свидетельство ac17/c01](d1-o1a-observer-full-send.ru.md), не дублируя старые бинарники и дерево исходников. Этот диагностический результат не подтверждает исходные метрики периодического/reconnect О1а, baseline, предел 512 000 000 байт или весь D1 и не является разрешением выпуска либо публичной активации.
