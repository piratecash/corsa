# v2.6.72 pin-store startup checks

The daemon built from `5bffcb5f4fe9ebe41995d1281af43283820e12fc` passed the startup checks below on November 15–16, 2026. The tests used temporary state, an isolated network and the standard daemon entry point.

| Platform | Daemon SHA-256 | Checks |
| --- | --- | --- |
| Native macOS arm64 | `a0f162cbecd042c583f866164a19ed3c514294d27c3ea860e0b56a6158cc3b76` | Two successful starts with an existing pin and marker. Refusal for an unsafe directory, an unsafe store mode, a store symlink, a damaged store, a missing store with an existing marker, an unsafe marker mode and a marker symlink. A daemon running as UID 501 refused a real UID 0 regular file with `location_unsafe / foreign_owner`. The file's inode, mode, owner, mtime and digest were unchanged. The daemon's sandbox allowed file writes only under its temporary workspace and network access only on loopback. |
| Ubuntu 24.04 Linux amd64 in Docker | `f0da1eaad7765697ac47d8ddb50e7077a2ff45232a35a66f79b8e551e1a9796b` | Two successful starts with an existing pin and marker. Refusal for an unsafe directory, an unsafe store mode, a store symlink, a damaged store, a missing store with an existing marker, and a foreign-owned directory and store file. Separate tests verified a foreign-owned marker, a writable marker and a marker symlink. The daemon ran as UID 24001 and the foreign owner was UID 24002. The marker tests used a seccomp profile to kill any attempt to call `bind` or `listen`. Both positive controls triggered the profile, and each refusal exited with code 1 and preserved the store, marker and symlink target. The container ran with `--network none`. |

Native macOS tests also passed for extended ACLs on the store, marker and directory, the Desktop startup refusal and resource cleanup, the SDK startup refusal, marker location and ownership rules. The daemon logs the typed cause locally and preserves the pin and marker on failure. The existing owner decision defers native Windows owner, DACL and reparse-point startup checks, which remain unverified.
