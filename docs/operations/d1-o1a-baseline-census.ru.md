# О‑1а: отказ при получении финальных свидетельств baseline

Периодическая попытка `5a3698c0ef0e437eeefebfac4d04e933` завершилась **Go FAIL**
через 480,60 с. Первая ошибка — `final process accounting unavailable`.
О‑1а и сравнение с текущим PR‑6 не зачтены; Б/с остаются **UNKNOWN**.
Переподключение не запускалось, одинакового повтора нет.

Испытывался пересобранный v2.6.72 `4fcc2f7245095fc43d2225f0f0065f4ce3b26113`
плюс три точные правки стенда: финализация namespace после поднятия carrier
и соответствующий существующий source guard. Измеряемые 640 исходников Core
остались прежними (`b70de373…`); 705 файлов стенда имеют новый stamp
`52e346f971a30a1d`. Это база с исправленным стендом, не опубликованный K11.

Четыре ELF, source archive и производные PID1/capexec проверены независимо.
Исходный Go API подтвердил полные манифесты 640/705 и `VerifyTree`;
10 тестов PID1 прошли. Историческая seccomp policy осталась побайтно прежней:
147 инструкций и 52 проверки. Capexec использует три environment SHA;
неиспользуемый исторический `NODE_SHA` не объявляется четвёртой защитой —
Node ELF проверяется PID1 через `FrozenArtifacts` и boot inputs.

Сохранены прежние 10 000 маршрутов, профили и окна 240/55 с, kernel `9ffe…`,
полный Native worker `7b75…`, гость 2 vCPU/1536 MiB без NIC/дисков/host sharing.
Этот запуск не измеряет standalone память под 512 000 000 байт.

Последняя сохранённая сводка указывает action/sample на 390-й секунде
(индексы сэмплов 52/53). Она не заменяет полного итогового отчёта.
После отказа оба target/helper завершились с кодом 1; `ended_not_exact`
и poison являются последующими отказами проверки, а не доказанной причиной.
`WaitFailed=true` само по себе не означает ошибку системного `wait`.

Exporter завершился с кодом 0. Полный capsule содержит 1345 исходников,
два манифеста и единственную `.failed` запись: 2843 байта, `body_bytes=0`.
Точная первая ветвь отказа не восстанавливается. По исходникам путь census
объединяет несколько ошибок clock/RPC/registry/full-receipts в одно сообщение.
Следующий шаг — закрытые безопасные коды стадий и отдельные компонентные
проверки; метрики и исходные критерии не ослабляются.

Console/native/stderr сохранены полностью: 6 913 656 / 992 / 0 байт.
VM остановилась штатно, worker exit0/reaped, дочерние процессы reaped,
без TERM/KILL или вмешательства контроллера. ROOT, TESTER и REVIEWER
независимо подтвердили остановку; ACK удалил только точный собственный lock.
Физическое освобождение всех XPC-ресурсов остаётся UNKNOWN.
