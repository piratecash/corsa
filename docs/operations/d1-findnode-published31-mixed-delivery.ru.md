# Published protocol 31: доставка при ожидающем FIND_NODE

Одна офлайн функциональная попытка прошла: **1 внешний тест /2 случая за 7,09 секунды**. Получатель — фиксированный опубликованный Linux ELF v2.5.71 `06e26f9b…`, без пересборки baseline. Он подключался к текущему Service внутри статического Linux Node.test; зашифрованное DM отправлял текущий Service. Проверены обычная конструкция Off и приватный неизменяемый Responder. Production-конструкторы и публичная активация не менялись.

В случае Responder участвовали два настоящих F1-клиента. У старого пира подтверждена identity protocol 31 без F1; исходный прямой маршрут и ключ естественно становились готовы до начала запроса. Получение сообщения через реальный RPC старого inbox и расшифровка тестовым декодером завершились при исходных **Pending1/Taken1/Answered0**. Затем прошли подписанный ответ FIND_NODE и точное сохранение исходных непрозрачных Session/ConnID. В обоих случаях завершились `delivered`, `seen` и `seen_ack`; у Responder — после подписанного ответа. Старый демон штатно завершился, его собственная группа исчезла. Это проверка доставки демоном и тестовым декодером, не старого Desktop-приложения.

До запуска прошли семь source-guard тестов /15 дочерних контролей; статический Linux amd64/CGO0 ELF собран на Go 1.27.4 с точными BuildInfo-зависимостями. Прежнего QEMU-образа не оказалось, поэтому подготовлен один собственный новый образ из аутентифицированных официальных пакетов и фиксированного старого ядра. Исходный metadata STOP и восстановление только метаданных сохранены. Свежая проба подтвердила x86_64, glibc 2.36 и ровно `{lo}` в стартовом и новом независимом netns. Функциональная VM завершилась с кодом 0 без OOM, её собственный контейнер удалён. Во время функционального прогона образы не менялись; нужный собственный образ сохранён.

[Переносимый пакет](evidence/d1-published31-mixed-delivery-2026-11-20/README.md) связывает две проверенные тестовые правки, полные RAW/старые журналы, происхождение бинарника, квалификацию и очистку. Дополнительная негативная proc-parser функция скомпилирована, но **NOT_RUN**. Исторические host CLI PID/PGID не записаны; сохранены свидетельства reap/пустой группы wrapper и свежего отсутствия собственных ресурсов. Эта односторонняя проверка не является полным H-mix/13b, статистикой задержек, приёмкой 512 МБ, K11, D1/G2 или выпуска. [Замер 512 churn](evidence/d1-churn512-current-2026-11-20/README.md) остаётся отдельным фиксированным срезом.
