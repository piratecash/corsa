# C3e: жизненный цикл исходной пересылки, неактивный Source срез

Реализована цепочка C3d receive → единственный scheduler → настоящие C3b/C3c → исходная очередь Node/NetCore → свежий Take → raw Write → обязательный Finish. Runtime остаётся Constructing, Ready выключен, SealConstruction не вызывается.

Scheduler просыпается после каждой завершённой OfferReceived, включая законный отказ, открывший пустой защищённый интервал. Один timer не продлевает фиксированный cut. Все реальные успешные C3a receipts доходят до исходного core либо явно отменяются, даже если следующий кандидат отказал.

Node выбирает исходный Session/common/concrete core до очереди. Handle одноразовый и сохраняет точные receipt/alias/request/received tuple. Ожидание будущего calendar slot и установка socket deadline проходят до Take. Take после всех application waits получает один настоящий свежий point, проверяет originals, alias/deadline/budgets и cleanup debt. После успешного Take нет диагностической публикации, нового lookup или очереди: следующий writer action — raw Write. Этот writer-start point не является local TargetCoordinator AdmittedAtT.

Только полный n==len(data) и nil error дают успех записи. Настоящий Finish обязателен до capture callback/deadline clear. Ошибка deadline отменяет работу до Take; partial/error write и ошибка Finish закрывают writer и запускают отмену очереди. Завершение использует заранее сохранённый Observer.ReserveClock и genuine Matches; конструктор только сохраняет роли и сам не доказывает общий domain. End/закрытый done не препятствуют завершению уже начатой записи. Foreign/poison не создают fake now и не возвращают принятый долг или ID.

Исходный transport End сначала выполняет прежнюю публикацию Session.End под common/W. Exact intake retirement вызывается после их освобождения. Dispatching сохраняется как TerminalDispatch до Finish, без application wait под common/W.

Source guards фиксируют 13 production файлов и точные caller/type/role/raw/body pins. Проверки включают настоящий original-core idle writer, пустой protected sweep, одноразовость, future slot, отмену и долг, End, foreign/poison completion и отсутствие post-Take диагностического ожидания. Отдельные fault endpoint fixtures используют genuine Node/TLS originals и настоящий Offer/C3b/C3c, проверяя NetCore writer; они не заменяют fixture исходного зарегистрированного socket. Native format/compile/ordinary/race и причинные контроли выполняет только ROOT на exact composed artifact. Старые native факты не переносятся.

Остаются local self-target/TargetCoordinator AdmittedAtT/signing/answer writer, discovery неизвестной цели, matching/relay ответа, caller/challenge terminal inverse closure, полный construction writer inventory и sealConstructionReady. Этот Source срез не является D1 Ready или разрешением активации/релиза.

Исправление принятого обязательства: после всех coordinator/pending/calendar waits Take использует отдельный original Consumer.ReserveAcceptedClock. Existing commit-role lease выделяется до блокировок, затем clock→auth.R; текущий stamp создаётся после обоих ожиданий, Sample один. Проверяются точные исходные source/target/receipt/alias, неизменные expiry/latest и actual pair/target budgets. Старые class/degree cut и unrelated cleanup не отменяют уже принятое обязательство. C3a first admission по-прежнему требует полный исторический cut/TryReadClock. Genuine start после latest явно учитывает assumption violation и освобождает exact row без возврата долга/ID. Done проверяется существующим Sample после raw/HWM. Исходный future-slot тест на границе не ослаблен; новые проверки покрывают unrelated W/End и pending row другой calendar, изменённую после housekeeping. Ready и допуск памяти/ресурсов не заявляются.
